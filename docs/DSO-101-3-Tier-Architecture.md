# DSO-101: Map the 3-Tier Architecture

**Documented by:** Emmanuella Blessing Udeh  
**Date:** October 2026

## Summary
Mapped PostureSec’s 3-tier architecture, including tiers, ports, and trust boundaries.

- **Frontend:** Nginx on ports 80/443 (public-facing)
- **Backend:** Express on port 3000
- **Database:** PostgreSQL on port 5432 (internal-only)

The documentation clearly shows why the database is never public-facing.
